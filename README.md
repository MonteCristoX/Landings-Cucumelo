# Landings Cucumelo Films

Landing pages especializadas para campañas de Google Ads.

## 📁 Estructura

| Archivo | Propósito | Palabras clave objetivo |
|---------|-----------|------------------------|
| `cucumelo-ai-video-generation.html` | Video con IA (ads, roll Bs, music videos) | "AI video generation", "AI video ads" |
| `cucumelo-ai-ads-landing.html` | Anuncios con IA | "AI ad production", "AI video ads agency" |
| `cucumelo-agency-landing.html` | Partner para agencias | "white-label production", "agency overflow" |
| `cucumelo-production-landing.html` | Producción premium | "film production", "documentary production" |

## 🚀 Deploy

- **Testing**: [Live Preview en GitHub Pages](https://montecristox.github.io/Landings-Cucumelo/)
- **Producción**: Subir a `cucumelofilms.com/landings/`

## 🔧 Personalización

1. Reemplazar imágenes de placeholder con fotos reales
2. Actualizar datos de contacto en formularios
3. Configurar Formspree con IDs reales
4. Actualizar URLs de Calendly/WhatsApp

## 🎨 Estilos

Todas las landings usan:
- CSS variables para tema oscuro/claro
- Fuente: Cabinet Grotesk + Satoshi
- Mobile-first responsive design
- Dark/Light mode toggle

## 📝 Notas de Perfil

- Bilingüe: English/Spanish
- Costa Rica-based production
- Modelo híbrido AI + Live-action
- Remote-first workflow
